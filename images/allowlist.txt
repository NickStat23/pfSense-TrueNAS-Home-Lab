# =====================================================================
#  PI-HOLE ALLOWLIST (WHITELIST)
#  Built 2026-09-14  --  tuned for: Amazon, YouTube, Yahoo Mail, TikTok,
#  Alexa/Fire TV, smart TVs & streaming, game consoles, WFH & banking.
#
#  SYNTAX USED IN THIS FILE
#    example.com     = exact allow      -> pihole allow example.com
#    *.example.com   = wildcard allow   -> pihole --allow-wild example.com
#                      (covers example.com AND everything under it)
#
#  Wildcards are used only where the whole domain is safe. Domains that
#  mix real content with ad servers (yahoo.com, google.com, facebook.com)
#  get exact entries only, so their ad subdomains stay blocked.
#
#  HOW TO USE
#    CLI    : run pihole-setup.sh (handles both types automatically)
#    Web UI : Domains -> Add. Paste the plain entries into the "Exact
#             allowlist" box; for the *. entries, strip the "*." and add
#             them to the "Regex allowlist" box as (\.|^)example\.com$
#  No gravity rebuild needed for allowlist changes -- they apply instantly.
# =====================================================================
